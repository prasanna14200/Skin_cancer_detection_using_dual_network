# Domain and input differences: observations versus hypotheses

**Observed facts.** Stage 23's frozen validation images are HAM10000 raw JPEGs (600×450), paper-preprocessed and saved as JPEGs before the deterministic 384×384 model view. The qualified PH2 follow-up uses original BMPs (among the 40 melanomas, approximately 764–768×575–576), runs the same `src/preprocessing.py` operations in memory, performs an OpenCV JPEG encode/decode to reproduce the HAM processed-JPEG representation, and then applies the frozen 384×384 tensor/normalization transform. Both use the same seven-class checkpoint, class order and selective-FP32 numerical policy; the PH2 run used T4 FP16 batch 16. The [PH2 protocol](../stage23_external_validation/STAGE23_EXTERNAL_VALIDATION_PROTOCOL.md) and [reproducibility audit](../stage23_external_validation/final_report/PH2_FOLLOWUP_REPRODUCIBILITY_AUDIT.md) fix those steps.

| Potential factor | Verified observation | Unresolved causal question |
|---|---|---|
| Label-space mismatch | HAM validation has seven true classes; PH2 maps only common NV and MEL, excludes 80 atypical nevi, and still permits five OTHER outputs. Fourteen of 27 PH2 MEL misses are OTHER (9 BKL, 4 DF, 1 AKIEC), versus 11 of 37 HAM MEL misses outside NV. | Whether some PH2 melanomas would receive a different diagnosis under a jointly harmonized seven-class pathology system cannot be inferred from these categories. Never relabel errors post hoc. |
| Source and encoding | HAM raw images are JPEG; PH2 source images are BMP and undergo an additional in-memory JPEG round trip to match the model-view representation. The archived input files and preprocessing code hashes are verified. | The independent effects of acquisition device, source encoding and JPEG round trip have **not** been isolated. |
| Resolution and geometry | HAM raw 600×450; PH2 MEL BMP roughly 764–768×575–576; both end at 384×384. | Resizing may alter fine detail differently, but no matched-resolution ablation on an independent development cohort exists. Raw Laplacian sharpness values are scale/encoding sensitive. |
| Color/brightness | Within PH2, raw brightness median is 156.28 for correctly classified MEL and 118.87 for missed MEL; raw saturation medians are 0.314 and 0.360. HAM brightness medians are about 150.43 and 152.01. These eight proxies are not expert quality labels. | Pigmentation, framing, source lighting, processing and lesion composition are confounded. The difference does **not** prove underexposure or color correction caused PH2 errors. |
| Blur sensitivity | Fixed synthetic HAM blur radius 1 changed MEL recall 70/107→16/107; radius 2 changed it to 2/107. Lower sharpness is associated with HAM MEL misses in Phase A. | Synthetic blur is not evidence that actual PH2 images were blurred or that a blur-specific training policy would transfer. |
| Model uncertainty | Within-true-MEL entropy error AUROC is 0.5927 on HAM, 0.5755 on PH2. Some HAM errors are highly confident. | Neither entropy nor confidence explains the external recall gap; both may be affected by shifts in logits. No calibrated clinical risk scale exists. |

**Interpretation:** the observed external drop and input/label differences are compatible with domain shift, but no single mechanism is causally identified. This is a previously used PH2 cohort, not untouched validation. Patient identity and possible site overlap cannot be fully resolved from the available IDs. Any mechanistic test must be preregistered on development data and confirmed on a new independent cohort, never selected from these PH2 errors.
