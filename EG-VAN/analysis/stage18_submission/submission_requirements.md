# PLOS ONE Research Article: checked submission requirements

Checked 6 October 2026 against the [official submission guidelines](https://journals.plos.org/plosone/s/submission-guidelines), [figure guide](https://journals.plos.org/plosone/s/figures), [supporting-information guide](https://journals.plos.org/plosone/s/supporting-information), [data policy](https://journals.plos.org/plosone/s/data-availability), [code policy](https://journals.plos.org/plosone/s/materials-software-and-code-sharing), [AI policy](https://journals.plos.org/plosone/s/ethical-publishing-practice) and [fee page](https://plos.org/fees/). “NOT VERIFIED” means the cited pages did not establish the rule or author-specific applicability; it does not mean the item can be omitted.

| Item | Status | Verified rule / preparation consequence |
|---|---|---|
| Article category | REQUIRED | Research Article is appropriate for original research. [Article types](https://journals.plos.org/plosone/s/what-we-publish). |
| Manuscript structure | REQUIRED | Title page, abstract, introduction; Methods, Results and Discussion; Acknowledgments, References, and supporting-information captions if applicable. Conclusions may be included. Main figures uploaded separately; tables in manuscript near first citation. |
| Title page and authors | REQUIRED | Full title, author names and affiliations on first page; short title also required. Full title ≤250 characters, short title ≤100 characters; sentence case. Corresponding author must have ORCID iD in submission profile. |
| Abstract | REQUIRED | ≤300 words; objective, approach, principal results and meaning; no references and preferably minimal abbreviations. |
| Keywords | NOT VERIFIED | The checked PLOS ONE manuscript guidelines did not establish a keyword count or mandatory manuscript keywords. Confirm submission-system fields. |
| Word/page limit | NOT REQUIRED | No overall word, figure-count or supporting-information amount limit; concise reporting encouraged. Manuscript double-spaced with continuous line numbering and page numbers; no footnotes. |
| Reference format | REQUIRED | Numbered citation-sequence Vancouver/ICMJE style; references ordered by first appearance; use journal abbreviations and complete details. |
| Main figures | REQUIRED | Individual TIFF or EPS files, named Fig1.tif etc.; 300–600 dpi; width 789–2250 px at 300 dpi, height ≤2625 px, file <10 MB; TIFF LZW compression and no alpha channel. Text 8–12 pt in specified fonts; captions in manuscript at first citation. Current PNGs require submission copies. |
| Tables | REQUIRED | Editable tables in manuscript directly after first textual citation, numbered in order with title above. Do not submit tables as figure files. |
| Supplement | OPTIONAL | If used, upload each file separately; file type broadly accepted, <20 MB per submission guideline (supporting-info page recommends <10 MB); S-numbered names and captions at end of manuscript. Existing four figures are relevant and retained. |
| Data availability | REQUIRED | Submission-form statement and public minimal data/metadata underlying findings by publication, unless a valid legal/ethical restriction is explained with access route. Do not claim that local files are already public. Dataset license/reuse permissions must be checked. |
| Code availability | REQUIRED for code underpinning findings | PLOS expects author-generated code underpinning findings to be available without restriction upon publication, documented for reuse; explain legitimate legal/ethical restrictions if any. A public repository/archive and license are author decisions. Whether the ~699 MB checkpoint must be deposited is **NOT VERIFIED**; seek editorial guidance if needed. |
| Funding disclosure | REQUIRED | Enter in submission system, **not** in manuscript file; grant numbers, recipients and funder roles, or truthful no-funding declaration. |
| Competing interests | REQUIRED | Enter in submission system, **not** in manuscript file; disclose all relevant financial/nonfinancial interests. |
| Author contributions | REQUIRED | At least one CRediT role per author in submission system. |
| Ethics statement | REQUIRED if human-subject/data policy applies; specific determination NOT VERIFIED | HAM/PH² image provenance and whether institutional approval/waiver is required must be assessed by responsible authors/institution. Do not invent an approval or exemption. [Human-subject guidance](https://journals.plos.org/plosone/s/human-subjects-research). |
| AI/tool disclosure | REQUIRED when AI contributed | Dedicated Methods section should name tools, use, output verification and affected study/manuscript components. Authors remain responsible for claims. Exact historical tool use beyond this editorial stage requires author confirmation. |
| Cover letter | REQUIRED | Separate file, ≤1 page; contribution, relationship to prior work, article type, prior PLOS interactions, suggested editors/opposed reviewers as applicable. No fee-waiver request in letter. |
| Graphical abstract | NOT VERIFIED | No requirement found in checked Research Article instructions. Do not create one solely for this stage. |
| Highlights | NOT VERIFIED | No requirement found in checked Research Article instructions. Do not create unsupported material. |
| ORCID | REQUIRED | Corresponding author's ORCID iD at submission. Other authors' ORCID requirement **NOT VERIFIED**. |
| Article APC | REQUIRED if accepted absent eligible support | Fully OA fee applies. Exact PLOS ONE individual dollar amount and author-specific institutional/assistance status **NOT VERIFIED** from reliably labeled official fee text; verify before submission. Assistance must be requested at submission if needed. |

This checklist is a preparation record, not a claim that placeholders satisfy submission requirements.
