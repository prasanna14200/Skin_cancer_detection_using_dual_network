# Fresh Stage 23-policy control versus one blur-augmentation treatment

**Prepared only; no training authorization.** The proposed Stage 4B selection subset is derived solely from original HAM train lesions. The frozen Stage 23 epoch-14 checkpoint is a historical reference and **must never be evaluated on this subset**: it already trained on every original HAM train image. Any result here would compare two *freshly trained* models, not replace or independently test frozen Stage 23.

## Exactly one selected Stage 4A hypothesis

Choose **rank 1: mild training-only Gaussian blur augmentation**. HAM validation Phase B showed marked sensitivity to *synthetic raw-image blur*, making blur robustness a question worth testing; it did **not** show that blur caused PH2 errors or that augmentation improves clean-image melanoma discrimination. Rank 2 exposure/contrast augmentation is not part of this study. No PH2 outcome, HAM test outcome, Stage 20 reliability result, or new Stage 4B selection outcome was used to choose this factor.

The controlled treatment factor is precisely one extra torchvision transform in the **training transform only**: after the existing `RandomRotation(15)` and before `ToTensor()`, apply `RandomApply([GaussianBlur(kernel_size=3, sigma=(0.1,0.5))], p=0.25)` to the processed PIL image after resize to 384×384. The fresh control retains the original Stage 23 transform (`Resize`, random horizontal flip, random vertical flip, random rotation, `ToTensor`, ImageNet normalization) without blur. The development-selection transform is identical and deterministic in both arms. This mild **post-preprocessing model-view blur** is not the raw pre-preprocessing blur used in Phase B; comparing them mechanistically would be invalid. Its parameters are frozen here before any Stage 4B model outcome, and no strength/probability sweep is permitted.

## Common model and training policy

Construct both arms independently from **identical initial state bytes**: same fixed seed 42, official hash-checked `ResNet50_Weights.IMAGENET1K_V2` trunk, same pretrained EfficientNetV2S initialization, same seeded newly initialized EG-VAN modules, seven-class order and architecture. Record the initial model-state hash in each arm and require equality before epoch 1. Do not load the trained Stage 23 checkpoint into either arm. Keep its Stage 23 paper-informed processed cache and 384-pixel input, focal loss (alpha 0.25, gamma 2, true-MEL multiplier 1.2815247721366766), weighted-sampler **policy** (MEL weight 1.5630495442733532, others 1.0, replacement), Adamax LR 0.001/weight decay 0.0001, ReduceLROnPlateau factor 0.5/patience 1, AMP with dynamic GradScaler and selective FP32 `resnet.nonlocal3` q@k unchanged. Both arms use the new **same** development-train manifest and internal-selection manifest only. `WeightedRandomSampler.num_samples` equals the new training subset length in both arms, a dataset-size consequence rather than an extra scientific factor. Maintain separate recorded RNG streams for common base sampling/augmentation and the treatment-only blur draw where the implementation allows; never claim identical stochastic trajectories without verified traces.

The development-selection subset contributes **zero gradient updates**. Original HAM val/test and PH2 paths, predictions and metric files must be inaccessible to training, selection, stopping and automated reporting code. Source/config/split hashes, class counts, image hashes, runtime, RNG/sampler states and all selection-subset predictions/metrics must be archived. No Stage 4B training runner or new checkpoint is created by this task.

## Prespecified comparison and stop rule

Both arms run up to exactly 25 epochs, absent fail-fast integrity/numerical failure; no metric-driven early stop, re-seeding or retrial until favorable. Within each arm, select the **minimum finite common unweighted internal-selection focal loss**, earliest epoch on an exact tie. This new internal rule does not change the original Stage 23 eligibility gates or its selected epoch. If no valid checkpoint exists, declare that arm invalid and stop candidate selection.

Primary paired treatment-minus-control measure: **MEL recall** on the *same* new internal-selection images, with true-MEL denominator and TP/FN counts. Guardrails: seven-class macro-F1 and **binary MEL specificity among true non-MEL images** (argmax MEL is positive). Also report accuracy, balanced accuracy, all classwise recall/F1, focal loss and seven-class confusion. Resample entire lesions **in parallel for both arms** (2,000 fixed-seed `20261010` cluster bootstrap replicates) for 95% intervals on paired differences. Patient-level inference is unavailable; disclose that limitation. Report support for every class and return INVALID if any class or needed denominator is absent.

An exploratory internal treatment candidate exists only if treatment MEL recall is greater than fresh control recall, the paired MEL-recall 95% lower bootstrap bound is above zero, and macro-F1 and binary MEL specificity do not decline in point estimate. Otherwise `NO_INTERNAL_CANDIDATE`. This stringent rule may fail with the available MEL count; do not relax it or search a second blur policy. Even an internal pass cannot establish improvement over the frozen Stage 23 checkpoint or clinical generalization. That comparison requires a new, unseen, patient-linked and label-mapped confirmation cohort with a separately frozen evaluation plan.

Hard-stop on changed or missing split/source hashes, original val/test/PH2 access, cross-role lesion/duplicate violation, absent class support, mismatched initial model hashes, corrupted optimizer/GradScaler/RNG/checkpoint history, non-finite logits/loss/state or unauthorized code/config change. Resume only from a verified same-run checkpoint and never extend 25 epochs. The proposed split's unresolved near-duplicate/patient issues are **pretraining gates**, detailed in [readiness](STAGE4B_READINESS.md).
