# Stage 4D remaining limitations

1. **Containment is screen-specific.** The v2 boundary contains the 40 previously refined cross-role pairs and all new pairs meeting the same two-stage screen after co-location. Zero refined cross-role pairs does **not** mean zero duplicate images. The v2 boundary still has 5,189 dHash-only cross-role candidate pairs; low-resolution dHash generates many lookalikes, and these have not been manually adjudicated. The pHash threshold can miss genuine relationships.
2. **Patient IDs are unavailable.** Lesion IDs are separated, but distinct lesion IDs may belong to the same person. HAM metadata age, sex, site and diagnosis are insufficient to prove or disprove patient overlap. Stage 4C human/source-image review remains unperformed. The 40 original pairs must never be described as confirmed duplicates.
3. **Selection is exploratory.** This selection cohort is newly held out from any future *fresh* Stage 4D control/treatment training but has no independently verified patient separation. Lesion-cluster confidence intervals cannot substitute for patient-cluster intervals. The 163 melanoma images represent 95 lesions, and rare classes remain small (DF 23 images / 12 lesions; VASC 19 / 16).
4. **Frozen Stage 23 cannot be tested on v2 selection.** Stage 23 trained on all original HAM train images, including both v2 roles. This boundary supports only freshly initialized model comparisons; it cannot validate replacement of Stage 23.
5. **Historical evaluation exposure persists.** Original HAM validation has been repeatedly used for development, and HAM test/PH2 outcomes were previously exposed elsewhere in the project. They are prohibited for Stage 4D training or selection. The previously ranked blur hypothesis was motivated partly by exploratory HAM validation robustness evidence, so a future v2 internal result will not be independent confirmation of that hypothesis.
6. **No future outcome yet.** The v2 manifests contain only data membership and image-source hashes. They establish no accuracy, melanoma recall, robustness gain, quality gate or clinical generalization. An independent, newly collected patient-linked confirmation cohort and a prospective evaluation protocol remain necessary for stronger claims.

The [Stage 4B fresh-control protocol](../stage4b_development_split/FRESH_CONTROL_VS_TREATMENT_PROTOCOL.md) is unchanged: control and Gaussian-blur treatment use the same v2 train/selection manifests, identical starting model state, the same selection rule and no old validation/test/PH2 inputs.
