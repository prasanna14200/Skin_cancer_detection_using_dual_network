## Image-quality finding

The eight measured proxies are brightness, contrast, Laplacian-variance sharpness, saturation, fraction of gray pixels below 30, fraction above 225, grayscale histogram entropy, and local illumination variation. Values 30 and 225 are **pixel-intensity definitions**, not image acceptability thresholds. The study measured all 10,015 **processed** HAM images (8,015/986/1,014 by frozen split). The Phase 7 baseline joined test quality terciles to errors, but did not define unusable-image labels, flag any specified count, or run a quality gate before classification. No registered quality accept/reject protocol was found in the audited implementation and reports. A prospective protocol is needed before defining one.

## Probability and explanation provenance

`final_ham_test_predictions.csv` has 1,014 rows with image ID, true class, predicted class, correctness, and `p_akiec` through `p_vasc`. `final_ph2_predictions.csv` has 120 rows with image ID, external and mapped true labels, predicted HAM class, and the same seven probabilities. **Neither file contains logits or a stored confidence column.** Confidence, entropy, margin and proper scoring rules can be derived from probabilities without model inference. The selected validation predictions contain 986 rows with seven probabilities in a `probabilities` field, which provides a validation source for a future review rule. Saved confidence alone is not proof of calibration.

The baseline uncertainty report uses the plain EfficientNetV2S epoch-6 checkpoint. The Experiment #5 calibration and Grad-CAM work uses the separate checkpoint SHA256 `81d567f533d08286d5e599b90512d96e92c413ad74c7f4f941d81fc7bb46de3a`, whereas the final EG-VAN checkpoint is `85fcad4b184da16dd741f2d539a05f8a1f0c8d1d015298f4ce5aadf7ef4d16d5`. These results cannot be pooled or relabeled as final-model reliability evidence.

## Accuracy claim

The **original paper reported approximately 98.20% accuracy, 95.74% recall, and 96.68% F1** for its reported task. Our **reconstructed seven-class** model achieved 82.347% accuracy, 0.699582 macro F1 and 0.958206 macro OVR AUC on the frozen HAM test. The architecture audit explicitly describes the paper result as nine-class, and implementation choices, data composition, split and leakage controls, and evaluation protocol differ. Thus whether the reconstruction *maintained the paper's 98.20% under an equivalent protocol* is **not established**; subtracting the two accuracies is not a valid direct comparison. The lower observed melanoma recall (56/107) is an important finding under our protocol, not a reason to alter results.

PH² external follow-up included 80 common nevi mapped to NV and 40 melanomas mapped to MEL; 80 atypical nevi were excluded. Accuracy was 0.666667, MEL recall 11/40 = 0.275, MEL F1 0.392857 and MEL probability AUC 0.542813. OTHER predictions remained errors. This documents limited transfer under this mapping, with the prior-use limitation intact.
