# Untouched external evaluation plan

**Current state:** PH² remains an **external follow-up**, not untouched validation: 120 included (80 NV, 40 MEL), 80 atypical nevi excluded, MEL recall 11/40, and prior project use. Its label space differs from HAM and OTHER predictions count as errors. Do not use PH² to tune thresholds, preprocessing or model selection.

**Recommended candidate: [BCN20000](https://www.nature.com/articles/s41597-024-03387-w)**, an independent Barcelona dermoscopy collection with 18,946 images from 5,583 lesions and multiple categories overlapping HAM’s seven labels. The [ISIC data page](https://challenge.isic-archive.com/data/) lists BCN20000 and HAM10000 separately. A repository text search found no BCN20000 use, but that alone does not prove the dataset is untouched; audit prior project use and source overlap before declaring an independent external lockbox. Do **not** download or evaluate it in Stage22.

Pre-register a mapping **before inspecting model predictions**: BCN nevus→NV, melanoma→MEL, basal cell carcinoma→BCC, seborrheic keratosis/solar lentigo→BKL only if source labels support that grouping, actinic keratosis→AKIEC only if label definition is compatible, dermatofibroma→DF, vascular lesion→VASC. Keep squamous cell carcinoma, ambiguous “other”, and out-of-distribution labels **out of seven-class mapped accuracy**; report their counts and a separate out-of-label/OOD response analysis, not silent exclusion. Publish exact inclusion/exclusion counts and source labels. Do not map every benign class to NV or every malignant class to MEL.

Before evaluating a frozen model, check image IDs/hashes and lesion metadata for any overlap with HAM and any pretrained/fine-tuning data where provenance is known. Freeze an independent lesion-disjoint BCN cohort and mapping; keep all images from a lesion together. Report full-cohort mapped seven-class accuracy, macro F1, balanced accuracy, classwise recall/F1 (especially MEL), confidence intervals, calibration and review coverage; report the excluded/OOD denominator separately. If some mapped classes lack sufficient support, report them as not estimable rather than treating BCN as a complete seven-class proof. Use one evaluation pass for a prespecified frozen candidate and prohibit further selection on BCN outcomes.

BCN20000 is a proposed **future** external test, not evidence already acquired. Its clinical sampling and hard locations are a useful transfer challenge, but category definitions and overlap screening are prerequisites. Any model developed after Stage16 test exposure requires a new untouched lockbox for a confirmatory performance claim.
