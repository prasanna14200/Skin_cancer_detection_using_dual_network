# Minimum credible image-quality completion plan

**Recommendation: Option A — explicit technical-quality reference labels with blinded validation.** Existing Stage20 features on *processed* images describe risk but cannot validate a pre-classifier accept/review/reject gate. A named public dataset could help, but compatibility with raw HAM dermoscopy and the proposed workflow is unproven; a new learned classifier would add cost and data requirements. A small, rigorously defined technical-quality study is the quickest defensible route.

1. Before viewing classification outcomes for the proposed quality cohort, publish an annotation rubric for raw images: severe focus loss, severe exposure/color failure, hair/markings obscuring lesion, framing/cropping loss, and unreadable/corrupt input. Labels: **acceptable**, **human quality review**, **technically unusable**. “Unusable” concerns technical interpretability, not diagnosis. Capture reason codes and ambiguity.
2. Use a lesion-disjoint quality development sample from HAM **train/validation only**, plus if feasible a separate prospectively chosen raw-image quality audit set. Keep HAM test and PH² diagnosis outcomes out of threshold development. Two trained independent raters blinded to diagnosis/model correctness; adjudicate disagreements. Record inter-rater agreement (weighted κ for ordinal labels and per-reason agreement). If no qualified raters are available, use prespecified objective artifact criteria and call the result a technical screening proxy, not an expert-validated quality gate.
3. Start with transparent raw-image features (focus/sharpness, under/overexposure, contrast, frame occlusion/hair burden) and an interpretable score or simple classifier. Define thresholds on quality **development** data only. A three-way gate may send ambiguous images to review; reject only for clearly unusable input. Never discard a case merely because the disease classifier is uncertain or wrong.
4. On a held-out lesion-disjoint quality validation set, report confusion matrix, per-class sensitivity/specificity, false-reject rate among acceptable images, review burden, quality AUROC/ordinal agreement, subgroup/class coverage where labels permit, and confidence intervals. Evaluate reviewer disagreement. Record what fraction of input types could be handled before downstream preprocessing.
5. Freeze rubric/model/cutoffs before any external evaluation. If validated performance is inadequate, status remains **PARTIAL**; retain descriptive quality risk. Quality labels must be independent of HAM diagnostic labels and classifier correctness.

No labels, cutoff, or quality gate were created in Stage22. Existing proxies and Stage20 non-monotonic associations are evidence for designing this study, not a validated accept/reject decision.
