# Prespecified Stage 3A analysis plan (no data analyzed)

## Locked inputs and units

Before rating, freeze cohort manifest, source hashes, grouping IDs, eligibility flow, review tokens, randomization seed, reviewer roster, calibration examples and this plan. The image is the annotation unit. Use patient clusters when verified patient IDs exist; otherwise use lesion clusters and state that patient independence is unverified. Never treat repeat images as independent in an interval calculation. Keep image representation fixed as raw acquisition image for primary ratings/proxies; any processed/resized analysis is separately labeled secondary.

## Primary agreement and label prevalence

Use the two independent overall ratings (0, 1, 2) before adjudication. Report category counts, unassessable/missing fractions, exact agreement, within-one-category agreement and linearly weighted Cohen kappa with its confusion table. Use a fixed-seed (42), 2,000-replicate patient- or lesion-cluster percentile bootstrap for 95% intervals; resample clusters, preserving all images and both reviewer ratings, and report bootstrap failures/undefined kappa. If imbalance produces a misleading kappa, show agreement and prevalence rather than post-hoc switching the primary endpoint. Report each domain's weighted kappa separately, with descriptive multiplicity caveat. For binary technical inadequacy (`2` vs `0/1`), report positive agreement and reviewer-specific prevalence. Adjudicated labels are the reference for proxy comparison, **not** independent ground truth.

## Proxy versus human annotation

Freeze the eight Phase A feature definitions from [`quality_metric_definitions.md`](../stage23_image_quality_final/phase_a/quality_metric_definitions.md): brightness, grayscale contrast, Laplacian variance, saturation, dark-pixel fraction, bright-pixel fraction, grayscale histogram entropy and illumination variation. Calculate them on raw pixels with versioned code and file hashes only after review labels are locked. No feature is assumed to point monotonically toward poor quality. First show source- and rating-stratified distributions and rank-biserial/ordinal associations with cluster-bootstrap intervals. For prespecified `overall=2` versus `0/1`, report each continuous feature's AUROC in both directions, labeling the favorable direction exploratory, plus average precision alongside the inadequate prevalence. Report all eight, without picking the best as an unbiased estimate or declaring a cutoff. Confidence intervals use the same cluster bootstrap; if either class is absent, mark AUROC/AP undefined.

Analyze domain-specific construct validity separately: sharpness versus focus, brightness/dark fraction versus exposure, contrast versus contrast rating, and other features only as exploratory. Hair and obstruction require direct reviewer tags; a generic scalar proxy is not an artifact detector. If model outcomes are later available under a separately frozen plan, estimate technical-adequacy/error association within source and diagnosis strata, using simple prespecified class/source-adjusted models only when event counts support them. Grouped out-of-fold fitting must keep entire patients/lesions in one fold, and fit imputation/scaling inside training folds. Do not fit a model now or borrow Stage 23 HAM/PH2 outcomes to select a quality threshold.

## Source versus quality

Report raw format, dimensions, site/device and adjudicated quality distributions by source. Compare quality/error relationships **within** source first; then summarize between-source differences with source adjustment and cluster intervals. A source-balanced analysis requires sufficient independent sources and overlapping quality ranges. If source and quality are perfectly confounded, report the two explanations as inseparable. Record acquisition metadata missingness and avoid treating JPEG/BMP or resolution as a causal quality explanation. New cohort predictions, if ever generated, must follow a prospectively frozen evaluation plan; Stage 3A does no inference.

## Sample size, exclusions and interpretation

Before collecting ratings, use the expected inadequate-image prevalence and cluster structure from an external planning source or a pilot *outside the analysis cohort* to select an enrollment target for the desired agreement-interval width. If this is unavailable, enroll all consecutive eligible images for a fixed prespecified period and report achieved interval width without claiming adequate power. Document denominators and every exclusion. Report unassessable images separately and perform a sensitivity analysis treating unresolved `U` as a distinct category. No imputation of scores or synthetic labels. No clinical diagnostic-adequacy claim, deployable quality gate or threshold follows from association alone; an untouched confirmation cohort would be required.
