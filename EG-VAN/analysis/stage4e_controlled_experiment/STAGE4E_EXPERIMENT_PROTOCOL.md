# Stage 4E paired fresh-control versus mild Gaussian-blur implementation

**Registered before any Stage 4E model training or internal-selection inference.** This is an exploratory fresh-model comparison on the [Stage 4D v2 split](../stage4d_conservative_split/stage4d_split_manifest_v2.json), manifest SHA256 `e218c9c2772452738cc53753d3b8857f1d321722a3e64b0b0e389442fcdadc93`. Stage 4D contains all 40 refined Stage 4C cross-boundary pairs on one side, but has no verified patient IDs or human pair adjudication. This design does not test or replace frozen Stage 23. The original Stage 23 checkpoint is never loaded, evaluated on v2, or changed.

## Single question and arms

Does adding **mild training-only Gaussian blur** improve melanoma recall in a fresh EG-VAN model without a point decline in seven-class macro-F1 or binary MEL specificity? The control and treatment use the same 6,477 processed HAM development-training images and 1,538 processed internal-selection images; no original HAM validation/test or PH2 loader exists in the Stage 4E path. The treatment adds only `RandomApply([GaussianBlur(kernel_size=3, sigma=(0.1, 0.5))], p=0.25)` after Stage 23's `RandomRotation(15)` and before `ToTensor()`. This is processed-image *model-view* blur, distinct from Phase B's raw-image degradations. No sweep or strength adjustment is allowed. Earlier Stage 4A ranking was partly motivated by exploratory HAM validation robustness evidence; no new historical evaluation outcome is used to fit this experiment.

Both arms instantiate the same complete dual-branch EG-VAN architecture used by Stage 23, but start from fresh ImageNet/pretrained initialization rather than Stage 23's trained checkpoint. Architecture provenance was resolved against the frozen Stage 23 checkpoint (SHA256 `42b018305694392ea874c1e9a4b28457adef780f7be9e740a16506404c9fc5ab`), its configuration and freeze registry, source definitions, initialization report, and checkpoint state dictionary. The checkpoint identifies `stage8b_egvan_four_mff_serial_terminal_branches`; the saved tensors have `efficient.*` and `resnet.*` branches, four `fusions.*` modules, `aggregate.*`, and `classifier.*`. Its metadata specifies EfficientNetV2-S taps `[2,3,5,7]`, ResNet stage channels `[256,512,1024,2048]`, SCGA after ResNet stages 1 and 2, non-local blocks after stages 3 and 4, four 128-channel serial MFFs, and terminal-branch aggregation. The frozen Stage 23 configuration and initialization report specify torchvision `EfficientNet_V2_S_Weights.DEFAULT` and hash-checked `ResNet50_Weights.IMAGENET1K_V2`; its model registry records the same architecture. This confirms the previous dual-branch description and corrects any ResNet-only characterization. Stage 4E does **not** load, evaluate, or modify that trained checkpoint.

Stage 4E's two fresh arms use official hash-checked torchvision `ResNet50_Weights.IMAGENET1K_V2` for the ResNet trunk, `EfficientNet_V2_S_Weights.DEFAULT` for the EfficientNet branch, and seed-42 PyTorch defaults for new modules. They must match a common pretraining state fingerprint recorded **before** either arm trains. Both use Stage 23 image size 384, physical/effective batch 16, Adamax LR 0.001/weight decay 0.0001, ReduceLROnPlateau factor 0.5/patience 1, training focal alpha 0.25/gamma 2/true-MEL multiplier 1.2815247721366766, and replacement WeightedRandomSampler with MEL weight 1.5630495442733532. The sampler draws exactly 6,477 training samples per epoch, a necessary change in count after replacing the data pool. CUDA AMP and dynamic GradScaler start at 8192; only `resnet.nonlocal3` q@k affinity is FP32. The selection transform contains **no blur or random augmentation** and uses the same common focal loss without MEL multiplier in both arms.

Use seed 42 for each fresh arm and record Python, NumPy, torch, CUDA and sampler RNG states at every completed epoch. Common initialization is checked bytewise through a canonical model-state hash; CUDA execution can still differ across machines, driver/cuDNN versions, and AMP kernels. The extra treatment random draw can alter later worker random trajectories; this experiment pairs by identical source images and initial weights, **not** by a claimed identical sequence of all random augmentations. No deterministic-GPU guarantee is claimed without an exact replay test.

## Selection and comparison fixed in advance

Run exactly 25 epochs per arm unless an integrity/numerical hard stop occurs. After every epoch, save complete internal-selection predictions/probabilities, seven-class confusion, accuracy, balanced accuracy, macro-F1, classwise precision/recall/F1, MEL TP/FN and binary MEL specificity (`TN/(TN+FP)` among true non-MEL). Train loss uses weighted focal objective; common internal-selection focal loss does **not** use MEL weighting. Select, within each arm, the epoch of **minimum finite common selection focal loss**; earliest epoch wins an exact tie. Do not select based on accuracy, melanoma recall, or a later comparison. This internal rule does not modify historical Stage 23 eligibility gates.

Only after both within-arm epochs are frozen, run the [saved-prediction comparison script](../../experiments/stage4e_control_vs_blur_exp1/evaluate_pair.py). Primary paired treatment-minus-control metric: melanoma recall on the same 163 true-MEL selection images. Guardrails: seven-class macro-F1 and binary MEL specificity on the same 1,375 true non-MEL images. Report accuracy, balanced accuracy and all classwise outcomes. Use 2,000 fixed-seed `20261010` **lesion-group paired bootstrap** replicates, resampling lesion IDs within each true class to retain class support; the same sampled lesions and repeated images go to both arms. Percentile 2.5% and 97.5% quantiles with NumPy's linear method give exploratory 95% intervals for paired differences. No patient-cluster interval is possible. A treatment is only an `INTERNAL_TREATMENT_CANDIDATE` if MEL recall is greater than control, the paired MEL-recall lower interval is **strictly above zero**, and neither macro-F1 nor MEL specificity declines in point estimate. Otherwise `NO_INTERNAL_CANDIDATE`. Missing class, missing denominator, failed provenance, or invalid epoch artifact makes comparison invalid, never a candidate. These thresholds cannot be changed after seeing results.

## Run and interruption policy

Colab T4 workflow: (1) read-only `--check`; (2) `--check-initialization`, which constructs two fresh models sequentially and writes a shared initial-state receipt without training/inference; (3) only after a separate user training authorization, run `--train --arm control` and `--train --arm treatment` once each. Each arm has a separate output directory. A completed epoch writes validation evidence and an **immutable full epoch checkpoint** in that arm's directory, containing model/optimizer/scheduler/GradScaler, complete history, best epoch/loss, Python/NumPy/torch/CUDA/sampler RNG, configuration and split/runner hashes. Resume requires an existing, integrity-checked latest epoch checkpoint and matching saved evidence; there is no fresh fallback. Never overwrite an epoch checkpoint or restart a favorable run. Full per-epoch checkpoints require substantial Drive space, approximately 0.7 GB × 25 ≈ 17.5 GB per arm plus validation evidence; check capacity before authorizing execution.

Hard stop for source/split/hash drift; overlapping image/lesion IDs; any original evaluation resource in the loader; mismatched initial fingerprints; non-finite logits/loss/model/buffers/optimizer; invalid GradScaler or unexplained optimizer skip; missing/corrupt checkpoint or history; class support/denominator failure; or unauthorized code/config change. A recoverable AMP overflow is logged only when GradScaler skips the step, backs off, and model/optimizer stay finite. Do not add clipping or alter the scientific factor.

The internal selection subset cannot independently establish improvement over frozen Stage 23. A new patient-linked, untouched cohort and separately frozen evaluation plan would be necessary for that claim. Stage 4E ends at implementation and CPU-safe preflight; it does **not** authorize GPU training.
